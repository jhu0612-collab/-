# 피슝이 (알림톡 대상자 추출 + 입장자체크)

매출 시트(클어/타이탄 공통 사용)를 기준으로 동작하는 두 가지 기능을 제공하는 Google Apps Script입니다.

1. **명단 추출**: "결제완료 + 카톡방 미입장" 상태인 사람을 뽑아, `카톡방` 열 값(반 이름) 기준으로
   나눠서 반별 엑셀 파일을 자동 생성.
2. **입장자체크**: 카카오톡 "대화 내보내기" 파일을 올리면, 실제로 입장한 사람을 매출시트에서
   찾아 `카톡방 입장` 체크박스를 자동으로 체크.

## 1) 명단 추출 - 동작 방식

1. 현재 보고 있는(활성) 탭의 헤더를 읽어 **클어/타이탄을 자동 판별**합니다.
   - `구매자` 헤더가 있으면 클어 → 상태열은 `결제상태`
   - `회원명` 헤더가 있으면 타이탄 → 상태열은 `주문상태`
   - 전화번호는 헤더에 "전화번호"가 포함되면 매칭 (전화번호/휴대전화번호 둘 다 인식)
2. 상태값이 정확히 `결제완료`인 행 중, `카톡방 입장` 셀 상태에 따라 3가지로 나뉩니다.
   - **체크박스가 있고 미체크** (빈 상자, 또는 값이 `false`/빈칸) → **추출됨**
   - **체크박스 자체가 없는 완전 공란** (환불자 등) → 제외
   - **체크박스가 있고 체크됨** (`true` 또는 "입장" 같은 값) → 제외

   구글시트에서는 "체크박스 있고 빈칸"과 "체크박스 자체가 없는 빈칸"이 셀 값만 봐서는
   똑같이 보이기 때문에, 셀 값(`getValues`)뿐 아니라 체크박스 서식 유무(`getDataValidations`)까지
   같이 확인해서 구분합니다. 체크박스는 진짜 불리언(true/false)이든 "입장"/빈칸 같은 커스텀
   텍스트 값이든 둘 다 자동으로 인식합니다.
3. 이름+전화번호가 같은 행(분할결제 등으로 인한 중복)은 1명으로 합칩니다.
4. `카톡방` 열 값으로 그룹을 나눕니다.
5. 다이얼로그 상단에서 고른 **출력 플랫폼(슝슝이/피콘)**에 따라 엑셀 형식이 정해집니다.
   (입력 탭이 클어형이든 타이탄형이든 상관없이, 순수하게 화면에서 고른 값 기준)
   - 슝슝이: 시트명 `발송 데이터`, 헤더 `연락처, #{고객명}, #{강좌명}, #{입장코드}, #{링크명}`
   - 피콘: 시트명 `sheet1`, 헤더 `연락처, 고객명, 강좌명, 입장코드, 링크명`
6. "대상 반 이름"과 일치하는 그룹만 반별로 엑셀 파일을 만듭니다.
7. 전화번호는 숫자만 남겨서 `010-1234-5678` 형식으로 변환합니다.
   - 시트에서 전화번호 셀이 "숫자" 서식으로 저장되어 맨 앞 0이 사라진 경우
     (예: `01090085800` → `1090085800`으로 보이는 경우) 자동으로 0을 복구합니다.
   - 그래도 한국 휴대폰 번호 형식(010/011/016/017/018/019, 10~11자리)이 아니면
     (외국인 번호 등) 그 사람은 명단에서 제외하고, 완료 메시지에 이름+원본 번호를 보여줍니다.
8. 반별 엑셀 파일들이 구글 드라이브를 거치지 않고, **각각 개별 `.xlsx` 파일로**
   실행한 사람의 컴퓨터에 순차적으로(0.4초 간격) 바로 다운로드됩니다.
   브라우저에 따라 "여러 파일을 다운로드하시겠습니까?" 같은 확인창이 한 번 뜰 수 있는데,
   허용해주시면 됩니다.

## 1) 명단 추출 - 입력 다이얼로그

- **출력 플랫폼(슝슝이/피콘)**: 상단 알약 모양 버튼으로 선택. 기본값은 슝슝이.
- **대상 반 이름**: 텍스트 입력창이지만, 현재 탭의 `카톡방` 열에 있는 값들이 자동완성
  목록으로 뜹니다. 목록에서 골라도 되고, 그냥 직접 타이핑해도 됩니다.
- **강좌명 / 입장코드 / 링크명**: 직접 입력.
- 기본 5행 제공, **"+ 반 추가"** 버튼으로 최대 30행까지 늘릴 수 있고,
  각 행 오른쪽 **"✕"** 버튼으로 필요 없는 행을 뺄 수 있습니다.
- **대상 반 이름을 비워둔 행은 무시**됩니다 — 10행을 만들어놔도 3행만 채우면 파일은 3개만 생성됩니다.
- **추출된 명단이 0명인 반은 엑셀을 만들지 않습니다.** 대신 결과란에 "명단 없음 (엑셀 생성 안 함)"으로 표시됩니다.
- 실행 중에는 진행 상태를 보여주는 게이지바가 표시됩니다 (전체 소요시간을 미리 알 수 없어
  애니메이션으로만 "작업 중"을 표시하고, 완료되면 사라집니다).

## 2) 입장자체크 - 동작 방식

1. 카카오톡 대화방에서 **"대화 내보내기"**로 저장한 원본 `.txt` 파일을 그대로 올린다
   (다른 처리 없이 원본 그대로 업로드하면 됨).
2. 파일 안에서 `OOO님이 들어왔습니다` 형태의 입장 시스템 메시지를 전부 찾아 닉네임을 추출한다.
   - 닉네임은 보통 "이름/전화번호뒷자리" 형식(예: `박보검/1234`)이지만, 구분자가
     슬래시(`/`)든 쉼표(`,`)든 아예 없든(`박보검1234`) 상관없이 인식한다.
   - 번호 없이 이름만 있는 닉네임(`승연`)도 지원한다.
3. 활성 탭에서 **아직 미입장(체크박스 있고 체크 안 됨)인 사람들** 중에서 매칭을 시도한다.
   - 전화번호 뒷자리가 있으면: **이름 일부 일치 + 전화번호 뒷자리 일치**를 모두 요구 (정확도 높음).
   - 전화번호 뒷자리가 없으면: **이름 일부 일치**만으로 매칭 (느슨함, 오매칭 가능성 있음).
4. 후보가 **정확히 1명**이면 그 사람의 `카톡방 입장`을 체크 처리한다
   (체크박스가 커스텀 값을 쓰면 그 값을, 표준 체크박스면 `true`를 넣음).
5. 후보가 **0명(매칭 실패)**이거나 **2명 이상(동명이인 등 모호함)**이면 자동으로 체크하지 않고
   결과 화면에 별도로 보고한다 — 사람이 직접 확인 필요.

## 설치 방법 (기존 프로젝트에 추가)

1. 대상 구글 시트에서 `확장 프로그램` → `Apps Script`로 기존 프로젝트를 연다.
2. `파일` 목록의 `+` → `스크립트` → 파일명을 `AttendanceCode`로 지정 →
   이 폴더의 `AttendanceCode.gs` 내용을 붙여넣는다.
3. `+` → `HTML` → 파일명을 정확히 `AttendanceDialog`로 지정 →
   이 폴더의 `AttendanceDialog.html` 내용을 붙여넣는다.
4. `+` → `HTML` → 파일명을 정확히 `EntryCheckDialog`로 지정 →
   이 폴더의 `EntryCheckDialog.html` 내용을 붙여넣는다.
5. 저장.

## 실행 방법

- 이미 프로젝트에 `onOpen()`이 있다면, 그 안에 아래 두 줄만 추가:
  ```js
  ui.createMenu('피슝이')
    .addItem('명단 추출', 'ATT_showDialog')
    .addItem('입장자체크', 'ATT_showEntryCheckDialog')
    .addToUi();
  ```
- 없다면 `AttendanceCode.gs` 맨 아래 `ATT_onOpen_template_` 함수 이름을 `onOpen`으로 바꿔서 사용.
- 등록 후 새로고침하면 상단에 **`피슝이`** 메뉴가 생기고, 그 안에 `명단 추출` / `입장자체크` 두 항목이 있습니다.
- **반드시 처리하려는 매출 탭을 열어둔 상태에서** 메뉴를 클릭하세요 (활성 탭 기준으로 동작).

## 필요한 열 (헤더명 기준, 위치는 상관없음)

| 역할 | 클어 | 타이탄 |
|---|---|---|
| 이름 | 구매자 | 회원명 |
| 전화번호 | 전화번호 | 휴대전화번호 |
| 결제상태 | 결제상태 (값: 결제완료) | 주문상태 (값: 결제완료) |
| 카톡방 입장 | 카톡방 입장 (체크박스) | 카톡방 입장 (체크박스) |
| 반 구분 | 카톡방 | 카톡방 |

## 커스터마이징

- 상태값(`결제완료`)이나 카톡방입장 헤더명을 바꾸려면 `AttendanceCode.gs` 상단 상수
  (`ATT_STATUS_OK_VALUE`, `ATT_ENTRY_HEADER`, `ATT_ROOM_HEADER`)를 수정하세요.
- 최대 반 개수(30)를 바꾸려면 `ATT_MAX_ROWS`를 수정하세요.
