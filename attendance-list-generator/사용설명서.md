# 📋 피슝이 - 사용 설명서

매출 시트(클어/타이탄 공통)를 기준으로 동작하는 두 가지 기능을 제공합니다.

1. **명단 추출**: 결제완료 + 카톡방 미입장 상태인 수강생을 찾아서, 반별로 나눠 엑셀 파일로 다운로드
2. **입장자체크**: 카카오톡 대화 내보내기 파일로 실제 입장자를 확인해서, 매출시트의 `카톡방 입장` 체크박스를 자동으로 체크

---

# 1️⃣ 명단 추출

## 1. 실행 방법

1. 매출 시트에서 **처리하고 싶은 탭(반)을 열어둔 상태**로 둔다.
   (이 도구는 화면에 지금 보고 있는 탭을 기준으로 동작합니다)
2. 상단 메뉴에서 **`피슝이`** → **`명단 추출`** 클릭.
3. 팝업창이 뜬다.

## 2. 화면 구성

### ① 대상 탭
- 지금 어느 탭을 기준으로 추출하는지 화면 위에 크게 표시됩니다.
- "시트 인식 중..." 문구가 사라지고 탭 이름이 뜨면 준비 완료.

### ② 출력 플랫폼 (슝슝이 / 피콘)
- 결과 엑셀의 형식을 결정합니다. 데이터 내용은 동일하고, 엑셀 파일의 시트 이름과 헤더 표기 방식만 다릅니다.
- **슝슝이**: 시트명 `발송 데이터`, 헤더에 `#{}` 표시가 붙음 (예: `#{고객명}`)
- **피콘**: 시트명 `sheet1`, 헤더에 기호 없이 일반 텍스트 (예: `고객명`)
- 원하는 쪽을 클릭해서 선택.

### ③ 반별 입력 표
| 항목 | 설명 |
|---|---|
| 대상 반 이름 | 시트의 `카톡방` 열에 적힌 값과 **정확히 똑같이** 입력 (자동완성 목록에서 골라도 됨) |
| 강좌명 | 발송할 때 표시될 강좌 이름 |
| 입장코드 | 카톡방 입장코드 |
| 링크명 | 카톡방 링크 이름 |

- 기본은 빈 표로 시작합니다. **"+ 반 추가"** 버튼을 눌러서 필요한 만큼 행을 만드세요 (최대 30개).
- 필요 없는 행은 오른쪽 **"✕"** 버튼으로 삭제.
- **대상 반 이름을 비워둔 행은 무시됩니다** — 안 써도 되니 그냥 빈 칸으로 남겨두면 됩니다.

### ④ 실행
- **"▶ 알림톡 대상자 추출"** 버튼 클릭.
- 진행 중에는 애니메이션 게이지바가 표시됩니다.
- 완료되면 반별 엑셀 파일이 **자동으로 순차 다운로드**됩니다 (내 컴퓨터의 기본 다운로드 폴더, 보통 `다운로드` 폴더).
  - 파일이 여러 개면 브라우저가 "여러 파일을 다운로드할까요?" 확인창을 한 번 띄울 수 있는데, 허용해주면 됩니다.

## 3. 누가 뽑히는가 (추출 규칙)

아래 조건을 **모두** 만족하는 사람만 추출됩니다.

1. **결제상태가 "결제완료"**인 사람만 (환불/취소 등은 자동 제외)
2. **카톡방 입장 체크박스가 있고, 체크가 안 되어 있는** 사람만
   - 체크박스가 있는데 체크 안 됨 → ✅ 추출
   - 체크박스 자체가 없는 완전 공란 (환불자 등) → ❌ 제외
   - 체크박스가 있고 이미 체크됨 → ❌ 제외
3. 이름과 전화번호가 같으면 **분할결제 등으로 여러 행이 있어도 1명으로만** 집계
4. **카톡방** 열에 적힌 값이 입력창에 적은 "대상 반 이름"과 일치하는 사람만 그 반의 엑셀에 포함

## 4. 전화번호 처리

- `010-1234-5678` 형식으로 자동 정리됩니다.
- 시트에서 숫자 서식 때문에 앞자리 0이 사라진 경우(`1090085800` 처럼 보이는 경우) 자동으로 복구합니다.
- 한국 휴대폰 번호 형식이 아닌 경우(외국인 등)는 명단에서 제외되고, **완료 메시지에 이름+번호가 따로 표시**됩니다 — 이 사람들은 수동으로 확인해서 처리해야 합니다.

## 5. 결과 메시지 읽는 법

실행 후 하단에 뜨는 메시지는 세 부분으로 구성됩니다.

- **✔ 엑셀 N개 다운로드 시작됨**: 정상적으로 생성된 반별 파일 목록 (반 이름, 인원수, 파일명)
- **⏭ 명단이 없어 건너뜀**: 입력한 반 이름과 일치하는 사람이 0명이라서 엑셀을 만들지 않은 반 목록
- **⚠ 번호 형식이 맞지 않아 제외됨**: 전화번호 형식이 이상해서 명단에서 빠진 사람 목록 (이름+원본 번호)

## 6. 자주 있을 수 있는 상황

- **대상 탭이 계속 "시트 인식 중"에 머물러 있다** → 시트가 크면 몇십 초 걸릴 수 있습니다. 계속 안 뜨면 창을 닫고 다시 열어보세요.
- **명단이 하나도 안 뽑힌다** → 입력한 "대상 반 이름"이 시트의 `카톡방` 열 값과 정확히 일치하는지 확인 (띄어쓰기, 괄호 등 포함해서 완전히 같아야 함).
- **엑셀에서 입장코드 등 숫자로 시작하는 값의 앞자리 0이 사라진다** → 이미 수정되어 있어야 정상입니다. 계속 발생하면 알려주세요.

# 2️⃣ 입장자체크

여러 반의 카카오톡 "대화 내보내기" 파일을 한 번에 올려서, 실제로 입장한 사람을 매출시트에서 찾아 확인하고, 확인 후에만 `카톡방 입장` 체크박스를 반영하는 기능입니다. **시트가 배정한 반과 실제로 입장한 반이 다른 사람도 자동으로 잡아냅니다.**

## 1. 실행 방법

1. 상단 메뉴에서 **`피슝이`** → **`입장자체크`** 클릭.
2. 팝업창이 뜬다.

## 2. 대화 내보내기 파일 준비

- 각 카톡방에서 **"대화 내보내기"**로 원본 `.txt` 파일을 저장한다 (다른 가공 없이 그대로 사용).
- 대화가 많아서 내보내기 파일이 여러 개로 쪼개졌다면, 나중에 업로드할 때 한 번에 여러 개를 선택하면 자동으로 파일명 순서대로 이어붙여서 처리합니다.

## 3. 화면 구성 및 사용법

### ① 대상 탭
- 지금 어느 탭을 기준으로 확인하는지 위에 표시됩니다. "시트 인식 중..."이 사라지면 준비 완료.

### ② 반(카톡방)별 파일 등록 표
| 항목 | 설명 |
|---|---|
| 반 이름 (카톡방 값) | 시트 `카톡방` 열 값과 **정확히 동일하게** 입력 (자동완성 지원) |
| 대화 내보내기 파일 | 그 반의 `.txt` 파일 업로드 (여러 개 선택 가능) |

- **"+ 반 추가"** 버튼으로 필요한 만큼 행을 만든다 (최대 30개, 기본 0개부터 직접 추가).
- 한 번에 여러 반을 동시에 등록할 수 있습니다 — 예: 1번방, 2번방, 3번방을 각각 한 행씩 만들고 각 반의 파일을 넣는 식.
- 반 이름을 비우거나 파일을 안 넣은 행은 무시됩니다.
- 필요 없는 행은 오른쪽 **"✕"** 버튼으로 삭제.

### ③ 실행
- **"▶ 입장자체크 (분석만, 시트 변경 없음)"** 버튼 클릭.
- 이 버튼은 **분석만 하고 시트를 바꾸지 않습니다.** 안심하고 눌러도 됩니다.

## 4. 매칭 규칙

1. 카톡 대화 안의 `OOO님이 들어왔습니다` / `OOO님이 나갔습니다` 메시지를 시간순 그대로 전부 인식합니다.
   - 닉네임은 "이름/전화번호뒷자리" 형식(예: `박보검/1234`)이 기본이지만, 구분자가 슬래시든 쉼표든 아예 없든 상관없이 인식합니다.
2. 매칭 대상은 **결제상태가 정확히 "결제완료"인 행만** (환불/취소 자동 제외 — 명단 추출과 동일 규칙).
3. **이름 + 전화번호 뒷자리(4~5자리)가 둘 다 일치**해야 확정 매칭됩니다.
   - 번호가 아예 없는 닉네임(예: `승연`) → 매칭 시도 안 함, "명단 외 입장자"로 처리.
   - 후보가 0명 → "명단 외 입장자".
   - 후보가 여러 명이어도 전부 이름+전화번호가 완전히 같으면(분할결제 등) → 같은 사람으로 보고 전부 확정.
   - 후보들의 이름+전화번호가 서로 다르면(진짜 동명이인) → "명단 외 입장자".
4. **시트 전체(모든 반)를 대상으로 검색**하기 때문에, 지금 등록한 반이 아닌 다른 반에 배정된 사람이 이 로그에서 발견될 수도 있습니다 → 이 경우가 "방 불일치"입니다.
5. 같은 사람이 자기 배정 반 로그 안에서 입장/퇴장을 반복했으면, **가장 마지막(최신) 이벤트**를 최종 상태로 봅니다.

## 5. 결과 카드 5가지

버튼을 누르면 5개 카드가 뜨고, 카드를 클릭하면 명단이 펼쳐집니다.

| 카드 | 의미 |
|---|---|
| ✅ 입장자 | 자기 배정 반에서 최종 "입장"으로 확정된 사람 (이미 체크돼 있던 사람 포함) |
| ⚠️ 명단 외 입장자 | 확정 매칭이 안 된 입장 기록 (번호 없음 / 매칭 실패 / 동명이인 등) — 사유가 함께 표시됨 |
| 🚪 퇴장자 (최종) | 확정 매칭됐지만 최종 상태가 "퇴장"인 사람 (체크하지 않음, 정보 표시용) |
| 🈳 미입장자 | 배정 반 파일이 있는데도 그 로그에 아예 등장하지 않은 사람 |
| 🔀 다른 반에 입장 (방 불일치) | **시트엔 A반으로 배정되어 있는데 B반 파일에서 입장이 확인된 사람.** "배정: A반 → 실제 입장: B반" 형식으로 표시. 자동으로 체크되지 않으며, 담당자가 직접 확인 후 내보내기 등 조치가 필요한 대상입니다. |

- 명단은 기본 **"이름 / 뒷4자리"**로 마스킹되어 표시되고, **"번호 전체보기"** 체크박스를 켜면 이름+전화번호 전체가 보입니다.
- 각 카드 상단의 **"📋 복사"** 버튼으로 그 명단 전체를 클립보드로 복사할 수 있습니다.

## 6. 반영하기

- 결과를 확인한 뒤 **"✅ 반영하기"** 버튼을 눌러야만 실제로 시트에 반영됩니다.
- **"입장자" 카드 목록만** 시트의 `카톡방 입장` 체크박스가 체크됩니다.
- **"방 불일치" 인원은 반영하기를 눌러도 체크되지 않습니다** — 시트에 잘못 배정되어 있거나 다른 반으로 옮겨야 하는 경우이므로, 확인 후 수동으로 처리해야 합니다.
- 버튼을 누르지 않으면 시트는 전혀 바뀌지 않습니다.

## 7. 자주 있을 수 있는 상황

- **명단 외 입장자에 아는 사람 이름이 있다** → 카드를 펼치면 사유가 같이 나옵니다. "번호 없음"이면 카톡 닉네임에 전화번호 뒷자리가 없는 경우, "매칭 실패"면 시트에서 이름+번호가 일치하는 결제완료 행을 못 찾은 경우, "동명이인"이면 이름은 같은데 전화번호가 다른 후보가 여러 명 있는 경우입니다.
- **방 불일치 카드에 사람이 있다** → 그 사람은 시트 배정과 실제 입장 반이 다르다는 뜻입니다. 반을 다시 배정하거나, 잘못 입장한 반에서 내보내는 등 후속 조치를 검토하세요.
- **반영하기 버튼이 안 보인다** → 입장자가 0명이면 버튼이 표시되지 않습니다 (체크할 대상이 없기 때문).
