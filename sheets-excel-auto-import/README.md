# 엑셀 → 구글 시트 자동입력

거래내역 엑셀 파일을 업로드하면 지정된 구글 시트의 빈 행부터 `결제일 / 결제금액 / 구매자` 열에
자동으로 기재해주는 Google Apps Script입니다.

기존 Apps Script 프로젝트(예: `CPI 알리미`)에 이미 다른 스크립트(`Code.gs`, `free-lecture-bot.gs` 등)가
있는 경우를 대비해, 모든 함수/상수 이름에 `EAI_` 접두사를 붙여 이름 충돌을 피했고
`onOpen`은 정의하지 않았습니다.

## 동작 방식

1. 엑셀의 `일시`, `금액`, `계좌적요` 열을 읽는다.
2. 금액이 음수인 행(환불/이체 등)은 제외한다.
3. `일시` 기준 오름차순으로 정렬한다.
4. 대상 시트에서 A~W열이 전부 빈 첫 번째 행을 찾는다.
5. 그 행부터 순서대로 `결제일`(또는 `주문일시`), `결제금액`(또는 `주문금액`), `구매자`(또는 `회원명`)
   열에 값을 채워 넣는다.

## 설치 방법 (기존 프로젝트에 추가)

1. 대상 구글 시트를 열고 `확장 프로그램` → `Apps Script`로 기존 프로젝트를 연다.
2. 왼쪽 `파일` 목록의 `+` → `스크립트` 클릭 → 파일명을 `ExcelAutoImport`로 지정.
   (기존 `Code.gs`는 그대로 두고 새 파일로 추가 — 덮어쓰지 않는다)
3. 이 폴더의 `ExcelAutoImport.gs` 내용을 그대로 붙여넣는다.
4. `+` → `HTML` 클릭 → 파일명을 정확히 `UploadDialog`로 지정.
5. 이 폴더의 `UploadDialog.html` 내용을 그대로 붙여넣는다.
6. 저장(Ctrl+S / Cmd+S).

## 실행 방법

**메뉴 없이 바로 실행 (가장 안전, 추천)**

Apps Script 편집기 상단의 함수 선택 드롭다운(기존에 `checkCpiAndNotify` 등이 떠 있는 자리)에서
`EAI_showUploadDialog`를 선택하고 `▶ 실행`을 누른다. 대상 구글 시트 탭으로 이동하면
업로드 창이 떠 있다. (처음 실행 시 권한 승인 팝업이 뜨면 승인)

**시트 메뉴에 등록하고 싶다면**

- 이미 프로젝트에 `onOpen()` 함수가 있다면, 그 함수 안에 아래 한 줄만 추가:
  ```js
  ui.createMenu('엑셀 자동입력').addItem('엑셀 파일 업로드', 'EAI_showUploadDialog').addToUi();
  ```
- `onOpen()`이 아직 없다면 `ExcelAutoImport.gs` 맨 아래 `EAI_onOpen_template_` 함수를
  `onOpen`으로 이름만 바꿔서 사용해도 된다.
- 등록 후 시트를 새로고침하면 상단에 `엑셀 자동입력` 메뉴가 생긴다.

## 사용 방법

1. `EAI_showUploadDialog` 실행 (메뉴 등록 시 `엑셀 자동입력` → `엑셀 파일 업로드`).
2. 다운받은 거래내역 `.xlsx` 파일을 선택.
3. 인식된 건수가 표시되면 `시트에 반영` 클릭.
4. 완료 메시지가 뜨면 시트에 새 행들이 채워진 것을 확인.

## 커스터마이징

- 다른 탭으로 대상을 바꾸려면 `ExcelAutoImport.gs`의 `EAI_TARGET_SHEET_GID` 값을
  해당 탭 URL의 `gid=` 뒤 숫자로 변경하세요.
- 매핑 대상 열 이름(결제일/결제금액/구매자 등)을 바꾸려면
  `EAI_importRecords` 함수의 `headerCols['...']` 부분을 수정하세요.
- 빈 행 판정 범위(A~W)를 바꾸려면 `EAI_LAST_COL` 값을 수정하세요.
