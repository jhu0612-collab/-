# 엑셀 → 구글 시트 자동입력

거래내역 엑셀 파일을 업로드하면, **업로드 창에서 직접 선택한 탭**의 빈 행부터
`결제일 / 결제금액 / 구매자` 열에 자동으로 기재해주는 Google Apps Script입니다.
이미 기재된 값과 (결제일+결제금액+구매자)가 동일한 건은 중복으로 보고 자동으로 건너뜁니다.

> 이전 버전은 "현재 활성 탭"을 자동으로 인식해서 썼는데, 실행 방식에 따라 브라우저가
> 보고 있던 탭을 정확히 못 잡아 엉뚱한 탭에 써지는 문제가 있었습니다. 그래서 업로드
> 창에 탭을 직접 고르는 드롭다운을 추가해 사람이 눈으로 확인하고 선택하도록 바꿨습니다.

기존 Apps Script 프로젝트(예: `CPI 알리미`)에 이미 다른 스크립트(`Code.gs`, `free-lecture-bot.gs` 등)가
있는 경우를 대비해, 모든 함수/상수 이름에 `EAI_` 접두사를 붙여 이름 충돌을 피했습니다.

## 동작 방식

1. 업로드 창이 열리면 스프레드시트의 모든 탭 이름을 드롭다운으로 보여준다.
   (현재 활성 탭이 있으면 기본 선택값으로 미리 채워주지만, 직접 바꿀 수 있다)
2. 엑셀 파일을 선택하면 `일시`, `금액`, `계좌적요` 열을 읽는다.
3. `시트에 반영` 클릭 시, 선택한 탭을 대상으로 서버에서 처리:
   - 금액이 음수인 행(환불/이체 등) 제외
   - 대상 탭에 이미 (결제일/주문일시 + 결제금액/주문금액 + 구매자/회원명)이 완전히 같은 행이 있으면 중복 제외
   - 남은 데이터를 `일시` 기준 오름차순 정렬
   - 대상 탭에서 **결제일/결제금액/구매자 3개 열이 모두 비어있는** 첫 번째 행을 찾아 그 행부터
     순서대로 기재 (다른 열의 테두리/서식/번호/체크박스 등은 무시 — 오직 이 3개 열의 값 유무만 봄)
   - 결제일 셀은 `yyyy-mm-dd hh:mm` 형식(초 제외, 24시간제)으로 표시
   - 결제수단/결제방법 열이 있으면 `계좌이체`, 결제상태/주문상태 열이 있으면 `결제완료`를 함께 기재
   - 상품유형 열이 있으면 `강의`, 면세여부 열이 있으면 `면세`를 함께 기재
4. 완료 메시지에 `[탭이름] N건 추가 완료 (중복 M건 제외) (X행부터 기재)`로 결과를 보여준다.

## 설치 방법 (기존 프로젝트에 추가)

1. 대상 구글 시트를 열고 `확장 프로그램` → `Apps Script`로 기존 프로젝트를 연다.
2. 왼쪽 `파일` 목록의 `+` → `스크립트` 클릭 → 파일명을 `ExcelAutoImport`로 지정.
   (기존 `Code.gs`는 그대로 두고 새 파일로 추가 — 덮어쓰지 않는다)
3. 이 폴더의 `ExcelAutoImport.gs` 내용을 그대로 붙여넣는다.
4. `+` → `HTML` 클릭 → 파일명을 정확히 `UploadDialog`로 지정.
5. 이 폴더의 `UploadDialog.html` 내용을 그대로 붙여넣는다.
6. 저장(Ctrl+S / Cmd+S).

## 실행 방법

**메뉴 등록 (추천)**

- 이미 프로젝트에 `onOpen()` 함수가 있다면, 그 함수 안에 아래 한 줄만 추가:
  ```js
  ui.createMenu('계좌이체 반영').addItem('엑셀 파일 업로드', 'EAI_showUploadDialog').addToUi();
  ```
- `onOpen()`이 아직 없다면 `ExcelAutoImport.gs` 맨 아래 `EAI_onOpen_template_` 함수를
  `onOpen`으로 이름만 바꿔서 사용해도 된다.
- 등록 후 시트를 새로고침하면 상단에 `계좌이체 반영` 메뉴가 생긴다.

**메뉴 없이 바로 실행**

Apps Script 편집기 상단의 함수 선택 드롭다운에서 `EAI_showUploadDialog`를 선택하고
`▶ 실행`을 누른다. 대상 구글 시트 탭으로 이동하면 업로드 창이 떠 있다.

## 사용 방법

1. `엑셀 자동입력`(또는 지정한 메뉴명) → `엑셀 파일 업로드` 클릭 (또는 위 실행 방법으로 실행).
2. **드롭다운에서 반영할 탭을 확인/선택** — 자동으로 채워진 값이라도 원하는 탭이 맞는지 꼭 확인.
3. 다운받은 거래내역 `.xlsx` 파일을 선택.
4. 인식된 건수가 표시되면 `시트에 반영` 클릭.
5. 완료 메시지에서 어느 탭에 몇 건 추가됐는지, 몇 행부터 기재됐는지 확인.

## 커스터마이징

- 매핑 대상 열 이름(결제일/결제금액/구매자/결제수단/결제상태 등)을 바꾸려면
  `EAI_importRecords` 함수의 `headerCols['...']` 부분을 수정하세요.
- 고정값 `계좌이체` / `결제완료`를 바꾸려면 `EAI_importRecords`의 `setValue('계좌이체')`,
  `setValue('결제완료')` 부분을 수정하세요.
- 날짜 표시 형식을 바꾸려면 `.setNumberFormat('yyyy-mm-dd hh:mm')` 부분을 수정하세요.
- 중복 판정 기준(현재: 결제일+결제금액+구매자 완전 일치)을 바꾸려면 `EAI_makeKey_` 함수를 수정하세요.
