# 엑셀 → 구글 시트 자동입력

거래내역 엑셀 파일을 업로드하면 지정된 구글 시트의 빈 행부터 `결제일 / 결제금액 / 구매자` 열에
자동으로 기재해주는 Google Apps Script입니다.

## 동작 방식

1. 엑셀의 `일시`, `금액`, `계좌적요` 열을 읽는다.
2. 금액이 음수인 행(환불/이체 등)은 제외한다.
3. `일시` 기준 오름차순으로 정렬한다.
4. 대상 시트에서 A~W열이 전부 빈 첫 번째 행을 찾는다.
5. 그 행부터 순서대로 `결제일`(또는 `주문일시`), `결제금액`(또는 `주문금액`), `구매자`(또는 `회원명`)
   열에 값을 채워 넣는다.

## 설치 방법

1. 대상 구글 시트를 연다:
   https://docs.google.com/spreadsheets/d/17m7yXKC8Pow9ovak5j_5_74sNckMH2bldRR0C-lG78M
2. 상단 메뉴 `확장 프로그램` → `Apps Script` 클릭.
3. 기본으로 열려있는 `Code.gs` 내용을 지우고, 이 폴더의 `Code.gs` 내용을 그대로 붙여넣는다.
4. 왼쪽 `+` 버튼 → `HTML` 파일 추가 → 파일명을 정확히 `UploadDialog` 로 지정.
   (자동으로 `.html` 확장자가 붙습니다)
5. 이 폴더의 `UploadDialog.html` 내용을 그대로 붙여넣는다.
6. 저장(Ctrl+S / Cmd+S) 후, 구글 시트 탭으로 돌아와 새로고침(F5) 한다.
7. 새로고침 후 상단 메뉴에 `엑셀 자동입력` 메뉴가 생긴다.
   (처음 실행 시 Google 계정 권한 승인 팝업이 뜨면 승인)

## 사용 방법

1. 구글 시트에서 `엑셀 자동입력` → `엑셀 파일 업로드` 클릭.
2. 다운받은 거래내역 `.xlsx` 파일을 선택.
3. 인식된 건수가 표시되면 `시트에 반영` 클릭.
4. 완료 메시지가 뜨면 시트에 새 행들이 채워진 것을 확인.

## 커스터마이징

- 다른 탭으로 대상을 바꾸려면 `Code.gs`의 `TARGET_SHEET_GID` 값을
  해당 탭 URL의 `gid=` 뒤 숫자로 변경하세요.
- 매핑 대상 열 이름(결제일/결제금액/구매자 등)을 바꾸려면
  `importRecords` 함수의 `headerCols['...']` 부분을 수정하세요.
- 빈 행 판정 범위(A~W)를 바꾸려면 `LAST_COL` 값을 수정하세요.
