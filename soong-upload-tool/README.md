# 슝 업로드용 - 클어/타이탄 지원 버전

기존 `app.py`(구글시트 → 엑셀 자동 입력 툴)에 **클어 / 타이탄** 리스트 선택 기능을 추가했습니다.

## 바뀐 점

- 화면 맨 위에 **① 리스트 선택** 카드 추가 — `클어` / `타이탄` 라디오버튼.
- 열 설정(이름/카톡방입장/수강생/반배정 열 번호, 수강생 판정 값)을 `LIST_CONFIGS` 딕셔너리로 분리:
  ```python
  LIST_CONFIGS = {
      "클어": {"col_name": 2, "col_m": 12, "col_n": 13, "col_p": 15, "n_target": "수강생"},
      "타이탄": {"col_name": 2, "col_m": 12, "col_n": 13, "col_p": 15, "n_target": "수강생"},
  }
  ```
  현재는 두 리스트의 열 배치가 동일하게 확인되어 값이 같지만, 나중에 실제로 달라지면
  `타이탄` 항목의 숫자만 바꾸면 됩니다 (0-based 인덱스: A=0, B=1, C=2 ...).
- 전화번호 열 탐색을 정확히 일치(`==`)에서 포함(`in`) 조건으로 완화 —
  "전화번호" 뿐 아니라 "휴대전화번호"처럼 앞에 다른 글자가 붙어도 인식되도록 함.
- 실행 결과 메시지에 `[클어]` / `[타이탄]` 표시가 붙어서 어느 리스트로 처리했는지 확인 가능.
- 나머지 로직(시트 목록 불러오기, 반별 엑셀 분할 저장 등)은 기존과 동일.

## 적용 방법 (개발 지식 없어도 가능)

1. `C:\auto_excel\app.py`를 이 폴더의 `app.py`로 교체 (완료하셨다면 생략).
2. `C:\auto_excel` 안에 있는 기존 `.spec` 파일(한글 이름) 이름을 **`final.spec`** 으로 바꿔주세요.
   (마우스 오른쪽 클릭 → 이름 바꾸기)
3. 이 폴더의 `build.bat` 파일을 `C:\auto_excel` 안에 넣기.
4. `build.bat` 더블클릭 → 자동으로 설치/빌드 진행.
5. 완료되면 `C:\auto_excel\dist` 폴더 안에 새 exe 파일 생성됨 → 실행해서
   상단에 `클어 / 타이탄` 라디오버튼이 보이는지 확인.

(`dog.png`, `app_icon.ico` 등 기존 리소스 파일은 원래대로 `C:\auto_excel`에 있으면 됩니다)

## 나중에 타이탄 열 배치가 실제로 다르다고 확인되면

`app.py` 상단의 `LIST_CONFIGS["타이탄"]` 값만 수정하면 됩니다. 예를 들어 타이탄의
반배정 열이 Q열이라면 `"col_p": 15`를 `"col_p": 16`으로 바꾸는 식입니다.
