# 해구대 소싱 자동화 도구

한국어 키워드 하나만 입력하면 번역 → 타오바오 검색·수집 → 무게/배송비 계산 → 리스크 체크 → 쿠팡/스스 카테고리 코드 매칭 → 픽투셀 업로드용 엑셀 출력까지 **한 화면에서** 전부 처리해주는 도구예요. 여러 페이지를 왔다갔다할 필요 없이 위에서 아래로 순서대로 진행하면 돼요.

## 1. 실행 방법

### Windows
`실행.bat` 파일을 더블클릭하세요. 창이 잠깐 떴다가 곧바로 작업표시줄에 최소화되고, 잠시 후 브라우저가 자동으로 열려요.
(눈에 보이는 콘솔창 없이 조용히 실행돼요. 완전히 끄고 싶으면 `종료.bat`을 더블클릭하세요.)

문제가 생겨서 오류 로그를 봐야 하면 `문제해결용_콘솔로_실행.bat`을 대신 실행하세요. 이건 창을 숨기지 않고 그대로 보여줘요.

### Mac / Linux
터미널에서 이 폴더로 이동한 뒤:
```
chmod +x 실행.sh
./실행.sh
```

브라우저가 자동으로 안 열리면 터미널에 나오는 `Local URL` 주소(보통 http://localhost:8501)를 직접 열면 돼요.

## 2. 폴더 구조

```
프로그램/
  Home.py               전체 기능이 다 들어있는 단일 화면
  lib/                  실제 계산/API 호출 로직
  data/
    blacklist.txt          지재권 위험 키워드 목록 (직접 수정 가능)
    customs_excluded.txt   목록통관 배제 키워드 목록 (직접 수정 가능)
    service_excluded.txt   출장설치 등 서비스성 상품 제외 키워드 목록 (직접 수정 가능)
    ambiguous_brand_words.txt  일반 단어와 겹치는 브랜드 키워드 목록, "확인필요"로 분류됨 (직접 수정 가능)
    pick2sell_template.xlsx 픽투셀 엑셀 일괄등록 양식 원본 (건드리지 마세요)
    api_keys.local.json    입력한 API 키 자동저장 파일 (프로그램이 알아서 만듦)
    scraped_archive.csv    픽투셀로 내보낸 상품 URL 기록 (중복수집 방지용, 프로그램이 알아서 만듦)
  requirements.txt
  실행.bat                 평소 실행용 (창 자동 최소화)
  종료.bat                 프로그램 완전히 끄기
  문제해결용_콘솔로_실행.bat  오류 로그 확인용
  실행.sh                  Mac/Linux용
```

## 3. 필요한 API 키

| 용도 | API 키 |
|---|---|
| 번역, AI 카테고리 추천, 무게 추산, 카테고리 코드 매칭 | **Anthropic(Claude) API 키** — https://console.anthropic.com |
| 타오바오 검색·수집 | **Apify API 토큰** — https://apify.com 가입 후 Settings > API & Integrations |

두 개면 충분해요. 화면 실행 후 왼쪽 사이드바에 입력하면 돼요. **한번 입력하면 이 컴퓨터의 `data/api_keys.local.json` 파일에 자동 저장**돼서, 프로그램을 껐다 켜도 다시 입력할 필요 없어요. (지우고 싶으면 사이드바의 "저장된 키 삭제" 버튼을 누르세요.)

## 4. 사용 순서

1. **(선택) 카테고리 후보 찾기**: 셀러라이프 엑셀을 올리면 검색량 300~5,000 / 해외배송비율 20%+ / 해외배송 평균리뷰 1개+ / 브랜드키워드 제외 조건으로 자동 필터링하고, AI 2차 추천도 받을 수 있어요. 검색할 키워드가 이미 정해져 있으면 이 단계는 건너뛰어도 돼요.
2. **검색 → 수집 → 카테고리 매칭**: 키워드(예: "캠핑 랜턴" 또는 이미 알고 있는 중국어)와 가격범위를 넣고 **"검색·수집 실행"** 한 번만 누르면
   - 한국어로 넣으면 자동으로 중국어로 번역되고, 중국어로 넣으면 그대로 검색하면서 카테고리 매칭용 한국어로 자동 역번역돼요 (직접 언어 판단할 필요 없음)
   - 그 키워드로 Apify가 타오바오를 검색해서 상품 목록을 통째로 가져오고
   - 쿠팡·스스 카테고리 코드도 자동으로 매칭돼요. 정확히 일치하는 카테고리가 없으면 부분단어로 재시도하고, 그래도 없으면 대분류부터 추정해서라도 채워요 (이 경우 "[추정값]"으로 표시).
   - AI가 중국어 원본 상품명을 **한국어 SEO 판매용 제목("한국어상품명(SEO)" 컬럼)**으로 자동 변환해요. 검색 키워드가 앞에 오도록, 과장 표현 없이, 50자 이내로 만들어요. 표에서 마음에 안 들면 직접 고쳐도 돼요.
3. **무게 확인 및 배송비 계산**: **"AI로 상품별 무게 자동추산"**을 누르거나(게이밍 의자는 무겁게, 손톱깎이는 가볍게 판단), 일괄값 적용, 표에서 개별 수정도 가능해요. 확인 후 **"배송비 계산 + 리스크체크 실행"**을 누르면 무게 기준 배송비와 지재권/통관 위험여부가 계산돼요.
4. **최종 확인 및 다운로드**: 카테고리 코드가 틀렸으면 직접 고치고, 위험한 상품은 자동 제외한 채 **"픽투셀 양식 엑셀 만들기"**를 누르면 다운로드돼요.
5. 다운받은 엑셀을 **픽투셀 '엑셀로 일괄등록' 화면에 드래그**하면 등록 끝!

맨 아래에는 상품명 하나만 빠르게 위험 키워드 체크하는 보조 도구와, 아카이브(중복방지 기록) 관리 메뉴가 있어요.

### 마진 계산 방식 (추가마진 방식)
원가×마진율 계산은 **픽투셀이 자체 계정 설정대로 알아서** 하고, 저희 프로그램은 **무게 기준 배송비만 계산해서 "추가마진"(H컬럼)에 얹어요**. "목표대표가"(I컬럼)는 비워둬요 — 둘 다 채우면 픽투셀이 추가마진을 무시하기 때문이에요.

```
픽투셀이 계산: 원가 × (1 + 마진율)   ← 픽투셀 자체 설정 그대로
저희가 추가: + 배송비(무게 기준, 동백요금표) + 기본 추가마진(선택)
```

배송비를 마진율에 곱하지 않고 순수 덧셈으로만 얹기 때문에, 배송비에 다시 마진이 붙는 이중계산이 안 생겨요. 고객한테는 "추가마진"으로만 보여서 배송비가 무료인 것처럼 보여요.

### 자동수집 결과의 한계
Apify가 가져온 타오바오 URL에는 픽투셀이 원하는 `mi_id`(정확한 옵션 식별자)가 없어서, 픽투셀이 이 URL로 옵션 정보를 수집할 때 정확도가 약간 떨어질 수 있어요. 다만 판매가는 "추가마진" 방식으로 별도 계산하니 가격 자체는 영향받지 않아요.

무게는 Apify 상세정보 조회(추가과금) 대신, **AI(Claude)가 상품명을 보고 종류별로 추산**하는 방식이에요. 어디까지나 추정치라 참고용이고, 표에서 개별 상품을 직접 수정할 수도 있어요.

### 한국어 SEO 상품명 자동생성
타오바오 원본 제목은 중국어라 그대로 내보내면 픽투셀/쿠팡·스스에 중국어 이름으로 그대로 등록돼요. 그래서 검색·수집 시 AI가 자동으로 검색 키워드 기준 한국어 판매용 제목을 만들어서 "한국어상품명(SEO)" 컬럼에 넣어줘요. 이 컬럼이 있으면 리스크체크와 픽투셀 내보내기 둘 다 이 한국어 제목을 기준으로 동작해요 (AI 생성이 실패하면 원본 중국어 제목으로 대체돼요). 표에서 문구가 마음에 안 들면 직접 수정 가능해요.

### 카테고리 코드 자동매칭
픽투셀 양식에는 쿠팡 기준(8,470개)·스스 기준(3,687개) 카테고리 코드 표가 내장돼 있어요. **검색·수집 실행 시 자동으로** 한국어 키워드 기준으로 3단계로 매칭을 시도해요.
1. 키워드 전체가 그대로 경로에 포함된 후보를 찾고 (예: "구명조끼" → "스포츠/레져>수영/수상스포츠>...>구명조끼")
2. 못 찾으면 "낚시구명조끼"처럼 합성어일 수 있으니 2글자 이상 부분단어로 재시도하고
3. 그래도 못 찾으면 AI가 대분류(예: "스포츠/레져")부터 추정해서 그 안에서 가장 비슷한 코드를 골라요 (이 경우 결과가 "[추정값]"으로 표시돼요).

버튼을 따로 누를 필요 없어요. 둘 다 채워지거나 하나만 채워질 수도 있고(픽투셀은 둘 다 있으면 쿠팡 기준으로 매칭), 자동매칭이 틀렸으면 최종 확인 단계에서 직접 수정하면 돼요.

### 출장설치/서비스성 상품 자동 제외
"上门安装(출장설치)", "包安装(설치포함)" 같은 서비스성 상품은 실물이 아니라 중국 현지 설치기사 출장 서비스라 해외구매대행 자체가 불가능해요. `data/service_excluded.txt`에 있는 중국어 키워드가 타오바오 원본 제목에 포함되면 검색·수집 단계에서 자동으로 제외돼요. 목록은 메모장으로 열어서 계속 보완하면 돼요.

### 지재권/브랜드 리스크체크 (3단계: 안전/확인필요/위험)
"배송비 계산 + 리스크체크 실행" 시 상품명(한국어 SEO 제목 + 중국어 원본 둘 다)을 `data/blacklist.txt`(브랜드/캐릭터), `data/customs_excluded.txt`(목록통관 배제)와 대조해서 3단계로 분류해요.
- **위험**: 명확한 브랜드/캐릭터 키워드가 매칭됨 → "위험 상품은 제외하고 내보내기" 체크박스로 자동 제외 가능
- **확인필요**: "K2"/"지프"/"핑"처럼 브랜드명이면서 동시에 흔한 일반 단어와도 겹치는 키워드가 매칭됨 → 자동 제외하지 않고 그대로 내보내되, 메모 컬럼에 사유를 남겨서 실제 상품 페이지를 열어 브랜드 제품이 맞는지 직접 확인하도록 안내해요 (예: "캠핑"에 들어있는 "핑"처럼 완전히 무관한 경우까지 자동으로 걸러버리면 오히려 정상 상품이 대량으로 빠지기 때문)
- **안전**: 아무것도 안 걸림

`data/blacklist.txt`에는 지금 자동차/아웃도어/스포츠웨어/명품/전자기기/캐릭터·IP/식음료/화장품/자전거/오토바이/낚시용품/주방용품/국내 식품·유통 등 브랜드 수백 개가 기본으로 등록돼 있어요. 새 브랜드를 발견하면 메모장으로 열어서 계속 추가하면 되고, 일반 단어와 겹칠 만한 애매한 브랜드는 `data/ambiguous_brand_words.txt`에 추가하면 "위험" 대신 "확인필요"로 분류돼요.

### 중복 수집 방지
같은 키워드로 여러 번 수집하거나 비슷한 키워드를 여러 개 돌리면 같은 상품이 다시 나올 수 있어요. 픽투셀 양식으로 **내보낼 때 상품 URL이 `data/scraped_archive.csv`에 자동 기록**되고, 다음에 수집할 때 자동으로 걸러져요.

**"픽투셀 양식 엑셀 만들기" 버튼 위에 "내보낸 상품을 아카이브에 기록하기" 체크박스**가 있어요. 테스트 중이라 같은 상품을 계속 다시 뽑아보고 싶으면 체크를 풀어두세요 (그럼 아카이브에 안 남아서 다음에도 똑같이 뽑혀요). 실제로 등록을 끝낸 상품이면 체크된 상태(기본값) 그대로 두세요.

만약 검색 결과가 전부 이전 아카이브와 겹쳐서 신규 상품이 0개가 되면, 화면에 그 이유가 명확하게 안내돼요. 맨 아래 "📦 아카이브 관리"에서 지금까지 몇 개를 내보냈는지 확인하거나, 필요하면 통째로 초기화할 수 있어요.

## 5. 데이터 갱신이 필요한 부분

- **`data/blacklist.txt`, `data/customs_excluded.txt`**: 메모장으로 열어서 한 줄에 하나씩 추가/수정하면 돼요. 지금 들어있는 목록은 예시이니 실제 취급 카테고리에 맞게 계속 보완하세요.
- **`lib/shipping.py`**: 동백국제물류 요금표가 개정되면 이 파일의 숫자만 갱신하면 돼요. 지금은 2026년 기준 요금표로 만들어져 있어요.
- **`lib/rules.py`의 필터 기준값**: 강의 기준값(검색량 300~5,000 등)이 기본값이지만, 화면에서 매번 조정도 가능해요.
