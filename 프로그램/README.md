# 해구대 소싱 자동화 도구

셀럭홈즈(셀러라이프) 엑셀 → 카테고리/키워드 필터링 → AI 추천 → 번역 → Apify로 타오바오 자동수집 → 마진/가격 계산 → 리스크 체크 → 픽투셀 업로드용 엑셀 출력까지 자동으로 처리해주는 도구예요.

## 1. 실행 방법

### Windows
`실행.bat` 파일을 더블클릭하세요. 창이 잠깐 떴다가 곧바로 작업표시줄에 최소화되고, 잠시 후 브라우저가 자동으로 열려요.
(눈에 보이는 콘솔창 없이 조용히 실행돼요. 완전히 끄고 싶으면 `종료.bat`을 더블클릭하세요.)

문제가 생겨서 오류 로그를 봐야 하면 `문제해결용_콘솔로_실행.bat`을 대신 실행하세요. 이건 창을 숨기지 않고 그대로 보여줘요.

### Mac / Linux
터미널에서 이 폴더로 이동한 뒤:
```
chmod +x 실행.sh
./실행.sh
```

브라우저가 자동으로 안 열리면 터미널에 나오는 `Local URL` 주소(보통 http://localhost:8501)를 직접 열면 돼요.

## 3. 기능별 필요한 API 키

| 기능 | API 키 필요 여부 | 발급처 |
|---|---|---|
| 📊 카테고리 필터링 | 필요 없음 | - |
| 🤖 AI 카테고리 추천 | Anthropic(Claude) API 키 | https://console.anthropic.com |
| 🈶 키워드 번역 | Anthropic(Claude) API 키 (위와 동일한 키 사용) | https://console.anthropic.com |
| 🕷️ 자동수집 통합 | **Apify API 토큰** | https://apify.com 가입 후 Settings > API & Integrations |
| 💰 마진·가격 계산기 | 필요 없음 (환율은 수동 입력) | - |
| 🚫 리스크 필터 | 필요 없음 | - |

필요한 API 키는 **Anthropic(Claude) + Apify 두 개**예요. 프로그램 실행 후 왼쪽 사이드바에 입력하면 돼요. **한번 입력하면 이 컴퓨터의 `data/api_keys.local.json` 파일에 자동 저장**돼서, 프로그램을 껐다 켜도 다시 입력할 필요 없어요. (지우고 싶으면 사이드바의 "저장된 키 삭제" 버튼을 누르세요.)

(사이드바에 "한국수출입은행 환율 API 키" 칸도 있지만 선택사항이에요. 비워두고 마진계산기에서 환율을 직접 입력하면 됩니다.)

## 4. 사용 순서

1. **카테고리 필터링**: 셀러라이프에서 받은 엑셀을 업로드 → 검색량 300~5,000 / 해외배송비율 20%+ / 해외배송 평균리뷰 1개+ / 브랜드키워드 제외 조건으로 자동 필터링
2. **AI 카테고리 추천**: 필터링된 후보를 AI가 계절성·트렌드까지 고려해서 최종 추천
3. **키워드 번역**: 선택한 키워드를 중국어로 번역
4. **자동수집 통합** (핵심): 번역된 키워드 + 가격범위로 Apify가 타오바오를 검색해서 상품 목록을 통째로 가져옴 → 예상무게 직접 입력(대략 추산) → 무게 기준 배송비 계산 + 리스크체크 자동 실행 → 카테고리 코드 자동매칭 → **픽투셀 업로드용 엑셀 파일로 바로 출력**
5. **마진·가격 계산기 / 리스크 필터**: 개별 상품 하나만 빠르게 확인하고 싶을 때 쓰는 보조 도구 (평소엔 4번만 써도 됨)
6. 4번에서 만든 엑셀을 **픽투셀 '엑셀로 일괄등록' 화면에 드래그**하면 등록 끝

### 마진 계산 방식 (추가마진 방식)
원가×마진율 계산은 **픽투셀이 자체 계정 설정대로 알아서** 하고, 저희 프로그램은 **무게 기준 배송비만 계산해서 "추가마진"(H컬럼)에 얹어요**. "목표대표가"(I컬럼)는 비워둬요 — 둘 다 채우면 픽투셀이 추가마진을 무시하기 때문이에요.

```
픽투셀이 계산: 원가 × (1 + 마진율)   ← 픽투셀 자체 설정 그대로
저희가 추가: + 배송비(무게 기준, 동백요금표) + 기본 추가마진(선택)
```

배송비를 마진율에 곱하지 않고 순수 덧셈으로만 얹기 때문에, 배송비에 다시 마진이 붙는 이중계산이 안 생겨요. 고객한테는 "추가마진"으로만 보여서 배송비가 무료인 것처럼 보여요.

### 자동수집 결과의 한계
Apify가 가져온 타오바오 URL에는 픽투셀이 원하는 `mi_id`(정확한 옵션 식별자)가 없어서, 픽투셀이 이 URL로 옵션 정보를 수집할 때 정확도가 약간 떨어질 수 있어요.

무게는 상세정보 조회 없이 **직접 추산해서 입력**하는 방식이에요 (상세정보 조회는 추가과금이 있고, 그래도 무게가 없는 상품이 많아서 효과가 불확실해요).

### 카테고리 코드 자동매칭
픽투셀 양식에는 쿠팡 기준(8,470개)·스스 기준(3,687개) 카테고리 코드 표가 내장돼 있어요. "한국어 키워드"(예: "캠핑 랜턴")를 넣으면
1. 그 키워드가 경로에 포함된 후보를 먼저 추려내고 (예: "스포츠/레져>캠핑>랜턴/조명>랜턴")
2. AI가 후보 중 가장 적합한 코드 하나를 골라줘요.

둘 다 채우거나 하나만 채워도 되고(픽투셀은 둘 다 있으면 쿠팡 기준으로 매칭), 자동매칭이 틀렸으면 직접 수정할 수 있어요.

### 중복 수집 방지
같은 키워드로 여러 번 수집하거나 비슷한 키워드를 여러 개 돌리면 같은 상품이 다시 나올 수 있어요. 픽투셀 양식으로 **한번 내보낸 상품의 URL은 `data/scraped_archive.csv`에 자동 기록**되고, 다음에 수집할 때 자동으로 걸러져요. "🕷️ 자동수집 통합" 페이지 아래쪽 "📦 아카이브 관리"에서 지금까지 몇 개를 내보냈는지 확인하거나, 필요하면 초기화할 수 있어요.

## 5. 데이터 갱신이 필요한 부분

- **`data/blacklist.txt`, `data/customs_excluded.txt`**: 메모장으로 열어서 한 줄에 하나씩 추가/수정하면 돼요. 지금 들어있는 목록은 예시이니 실제 취급 카테고리에 맞게 계속 보완하세요.
- **`lib/shipping.py`**: 동백국제물류 요금표가 개정되면 이 파일의 숫자만 갱신하면 돼요. 지금은 2026년 기준 요금표로 만들어져 있어요.
- **`lib/rules.py`의 필터 기준값**: 강의 기준값(검색량 300~5,000 등)이 기본값이지만, 화면에서 매번 조정도 가능해요.

## 6. 참고: 마진 계산 원칙

배송비는 마진율(%)에 곱해서 반영하지 않고, **정액으로 최종가에 더해요**. 픽투셀에서 "배송비를 노출하지 않고 상품별 추가마진으로 반영"하라고 안내한 방식과 같은 원리예요.

```
최종판매가 = 원가(위안) × 환율 × (1 + 마진율) + 배송비(정액) + 추가마진(정액)
```
