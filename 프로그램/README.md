# 해구대 소싱 자동화 도구

셀럭홈즈(셀러라이프) 엑셀 → 카테고리/키워드 필터링 → AI 추천 → 번역 → (반자동 URL수집) → 마진/가격 계산 → 리스크 체크까지, 픽투셀 업로드 직전 단계까지 도와주는 도구예요.

## 1. 실행 방법

### Windows
`실행.bat` 파일을 더블클릭하세요. 처음 실행하면 필요한 패키지를 자동으로 설치한 뒤 브라우저가 열려요.

### Mac / Linux
터미널에서 이 폴더로 이동한 뒤:
```
chmod +x 실행.sh
./실행.sh
```

브라우저가 자동으로 안 열리면 터미널에 나오는 `Local URL` 주소(보통 http://localhost:8501)를 직접 열면 돼요.

## 2. 폴더 구조

```
프로그램/
  Home.py               첫 화면
  pages/                기능별 화면 5개
  lib/                  실제 계산/API 호출 로직
  data/
    blacklist.txt        지재권 위험 키워드 목록 (직접 수정 가능)
    customs_excluded.txt 목록통관 배제 키워드 목록 (직접 수정 가능)
  requirements.txt
  실행.bat / 실행.sh
```

## 3. 기능별 필요한 API 키

| 기능 | API 키 필요 여부 | 발급처 |
|---|---|---|
| 📊 카테고리 필터링 | 필요 없음 | - |
| 🤖 AI 카테고리 추천 | Anthropic(Claude) API 키 | https://console.anthropic.com |
| 🈶 키워드 번역 | Anthropic(Claude) API 키 (위와 동일한 키 사용) | https://console.anthropic.com |
| 💰 마진·가격 계산기 | 필요 없음 (환율은 수동 입력) | - |
| 🚫 리스크 필터 | 필요 없음 | - |

필요한 API 키는 **Anthropic(Claude) API 키 하나**면 충분해요. 프로그램 실행 후 왼쪽 사이드바에 입력하면 돼요. **파일에 저장되지 않고 화면을 켜둔 동안만 메모리에 유지**돼요. 껐다 켜면 다시 입력해야 해요.

(사이드바에 "한국수출입은행 환율 API 키" 칸도 있지만 선택사항이에요. 비워두고 마진계산기에서 환율을 직접 입력하면 됩니다.)

## 4. 사용 순서

1. **카테고리 필터링**: 셀러라이프에서 받은 엑셀을 업로드 → 검색량 300~5,000 / 해외배송비율 20%+ / 해외배송 평균리뷰 1개+ / 브랜드키워드 제외 조건으로 자동 필터링
2. **AI 카테고리 추천**: 필터링된 후보를 AI가 계절성·트렌드까지 고려해서 최종 추천
3. **키워드 번역**: 선택한 키워드를 중국어로 번역 → 이 키워드로 **셀러라이프 크롬 확장을 이용해 직접 타오바오/1688에서 검색**해서 마음에 드는 상품의 URL·가격(위안)·무게를 수집하세요 (이 단계는 자동화하지 않고 사람이 직접 함 — 유료 API 비용 대비 지금 물량에는 반자동이 더 경제적이라 이렇게 결정했어요)
4. **마진·가격 계산기**: 수집한 상품의 원가(위안)와 무게를 넣으면 환율 + 동백국제물류 배송비(정액) + 마진율을 반영한 최종 판매가 계산
5. **리스크 필터**: 상품명에 지재권/통관 위험 키워드가 있는지 체크
6. 최종 후보를 골라서 **픽투셀에 직접 업로드** (자동화 대상 아님)

## 5. 데이터 갱신이 필요한 부분

- **`data/blacklist.txt`, `data/customs_excluded.txt`**: 메모장으로 열어서 한 줄에 하나씩 추가/수정하면 돼요. 지금 들어있는 목록은 예시이니 실제 취급 카테고리에 맞게 계속 보완하세요.
- **`lib/shipping.py`**: 동백국제물류 요금표가 개정되면 이 파일의 숫자만 갱신하면 돼요. 지금은 2026년 기준 요금표로 만들어져 있어요.
- **`lib/rules.py`의 필터 기준값**: 강의 기준값(검색량 300~5,000 등)이 기본값이지만, 화면에서 매번 조정도 가능해요.

## 6. 참고: 마진 계산 원칙

배송비는 마진율(%)에 곱해서 반영하지 않고, **정액으로 최종가에 더해요**. 픽투셀에서 "배송비를 노출하지 않고 상품별 추가마진으로 반영"하라고 안내한 방식과 같은 원리예요.

```
최종판매가 = 원가(위안) × 환율 × (1 + 마진율) + 배송비(정액) + 추가마진(정액)
```
